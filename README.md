# Alis_test_TL

Веб-тест, который по ответам пользователя определяет **тип личности**.

## Идея

Пользователь заходит на сайт, отвечает на серию вопросов и получает результат:
тип личности, его сильные стороны, стиль общения и роль в команде.

За основу взят подход MBTI (как у 16Personalities), вопросы — в открытом
формате (по мотивам открытого определителя OEJTS), чтобы не нарушать
авторские права.

## Этапы

1. **Минимализм** — рабочий тест на чистом HTML/CSS/JS, без бэкенда.
   Результат считается прямо в браузере. Публикация на GitHub.
2. **Красиво** — дизайн, анимации, адаптив, подробные описания типов.
3. **Сервер** — деплой на VPS.

## Стек

Статический сайт: HTML + CSS + ванильный JavaScript. Без фреймворков и
бэкенда — тест полностью считается на стороне клиента.

## Структура

```
Alis_test_TL/
├── index.html      # страница теста
├── css/style.css   # стили
├── js/             # логика теста и подсчёт результата
└── data/           # вопросы и описания типов (JSON)
```
